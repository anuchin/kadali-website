# ಸದಸ್ಯೆಯರ ಪ್ರಕಟಣಾ ಮಾರ್ಗದರ್ಶಿ · Member Publishing Guide

ಈ ಕೈಪಿಡಿ ಕದಳಿ ಸಮಾಜದ ಸದಸ್ಯೆಯರಿಗೆ — ಫೋನಿನಿಂದಲೇ ಲೇಖನ ಮತ್ತು ಕಾರ್ಯಕ್ರಮ ಪ್ರಕಟಿಸಲು.

## 1. ಲಾಗಿನ್

1. ಫೋನಿನ ಬ್ರೌಸರಿನಲ್ಲಿ (Chrome) **admin.yourdomain.org** ತೆರೆಯಿರಿ.
2. **Sign in with GitHub** ಒತ್ತಿ, ನಿಮ್ಮ GitHub ಖಾತೆಯ ಮೂಲಕ ಪ್ರವೇಶಿಸಿ.
   (ಖಾತೆ ಇಲ್ಲದಿದ್ದರೆ ಸಮಿತಿಯವರು github.com ನಲ್ಲಿ ಉಚಿತ ಖಾತೆ ತೆರೆಯಲು ಸಹಾಯ ಮಾಡುತ್ತಾರೆ.)

## 2. ಹೊಸ ಲೇಖನ ಬರೆಯಲು

1. ಮುಖಪುಟದಲ್ಲಿ **ಲೇಖನಗಳು** → **ಹೊಸ ಲೇಖನ** (+) ಒತ್ತಿ.
2. ಕಂಡಿಗಳನ್ನು ತುಂಬಿರಿ:
   - **ಶೀರ್ಷಿಕೆ** — ಲೇಖನದ ಹೆಸರು
   - **ಸಂಕ್ಷಿಪ್ತ ವಿವರಣೆ** — ಎರಡು-ಮೂರು ಸಾಲಿನ ಸಾರಾಂಶ
   - **ಮುಖಚಿತ್ರ** — ಗ್ಯಾಲರಿಯಿಂದ ಫೋಟೋ ಆಯ್ಕೆ ಮಾಡಿ ಅಥವಾ ಫೋನಿನಿಂದ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ
   - **ವಿಭಾಗ** — ವಚನ / ಸಂಸ್ಕೃತಿ / ಸ್ಮರಣೆ / ಸೇವೆ / ಸಾಹಿತ್ಯ / ಸಮುದಾಯ
   - **ಲೇಖನ ವಿಷಯ** — ದೊಡ್ಡ ಪೆಟ್ಟಿಗೆ. ಬರೆಯುವಾಗ ಮೇಲಿನ ಪಟ್ಟಿಯಿಂದ
     **B** (ದಪ್ಪ), *I* (ಓರೆ), ಶೀರ್ಷಿಕೆ, • ಪಟ್ಟಿ, "ಉಲ್ಲೇಖ" ಒತ್ತಿ ಬಳಸಬಹುದು.
     ಇಮೋಜಿ/ಚಿತ್ರ ಅಂಟಿಸಬಹುದು.
3. ಬಲಗಡೆ **ಮುನ್ನೋಟ** (Preview) ನಲ್ಲಿ ಹೇಗೆ ಕಾಣುತ್ತದೆ ಎಂದು ನೋಡಿ.
4. **Save** ಒತ್ತಿ. ಇದು ಕರಡು (draft) — ತಕ್ಷಣ ಜಾಲತಾಣಕ್ಕೆ ಬರುವುದಿಲ್ಲ.
5. ಸಮಿತಿ ಅಧಿಕಾರಿ ಪರಿಶೀಲಿಸಿ **Publish** ಮಾಡಿದ ಕೂಡಲೇ, 2–3 ನಿಮಿಷದಲ್ಲಿ
   ಜಾಲತಾಣದಲ್ಲಿ ಲೇಖನ ಕಾಣಿಸುತ್ತದೆ.

## 3. ಹೊಸ ಕಾರ್ಯಕ್ರಮ ಸೇರಿಸಲು

1. **ಕಾರ್ಯಕ್ರಮಗಳು** → **ಹೊಸ** (+).
2. ಶೀರ್ಷಿಕೆ, ಸಂಕ್ಷಿಪ್ತ ವಿವರಣೆ, **ಪ್ರಾರಂಭ ದಿನಾಂಕ-ಸಮಯ** (ದಿನಾಂಕ ಆಯ್ಕೆಕಾರದಿಂದ),
   ಸ್ಥಳ, ಸಂಪರ್ಕ ಸಂಖ್ಯೆ ತುಂಬಿರಿ. ಪೋಸ್ಟರ್ ಇದ್ದರೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.
3. Save → ಅಧಿಕಾರಿ Publish ಮಾಡುತ್ತಾರೆ. ದಿನಾಂಕ ಮುಗಿದ ಮೇಲೆ ಕಾರ್ಯಕ್ರಮ
   ಸ್ವಯಂಚಾಲಿತವಾಗಿ "ಮುಗಿದಿದೆ" ಪಟ್ಟಿಗೆ ಹೋಗುತ್ತದೆ.

## 4. ಫೋಟೋ ಅಪ್‌ಲೋಡ್ (ಗ್ಯಾಲರಿ)

1. **ಚಿತ್ರಶಾಲೆ** → **ಹೊಸ** (+) → ಶೀರ್ಷಿಕೆ ಮತ್ತು ದಿನಾಂಕ ಕೊಡಿ.
2. **ಫೋಟೋಗಳು** → **Add** → ಫೋನಿನ ಗ್ಯಾಲರಿ ತೆರೆಯುತ್ತದೆ → ಫೋಟೋ ಆಯ್ಕೆ ಮಾಡಿ.
3. ದೊಡ್ಡ ಫೋಟೋಗಳು ಸ್ವಯಂಚಾಲಿತವಾಗಿ WebP ಆಗಿ ಸಂಕುಚಿತವಾಗುತ್ತವೆ —
   ಚಿಂತೆ ಬೇಡ, ನೇರವಾಗಿ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ (4 MB ಒಳಗೆ).

## 5. ನೆನಪಿಡಿ

- **Save** = ಕರಡು ಉಳಿಸಿತು. **Publish** = ಅಧಿಕಾರಿ ಪ್ರಕಟಿಸಿದರೆ ಮಾತ್ರ ಜಾಲತಾಣದಲ್ಲಿ ಕಾಣುತ್ತದೆ.
- ತಪ್ಪಾದರೆ ಎಂದಿಗೂ ಚಿಂತೆ ಬೇಡ — ಎಲ್ಲವೂ Git ಇತಿಹಾಸದಲ್ಲಿ ಉಳಿದಿದೆ, ಹಿಂದಕ್ಕೆ ತರಬಹುದು.
- ಸಮಸ್ಯೆ ಎದುರಾದರೆ ಸಮಿತಿ ಅಧಿಕಾರಿಗಳನ್ನು ಸಂಪರ್ಕಿಸಿ.
